# VPN avec OpenVPN et Gestion des Logs avec Loganalyzer

## Description
Mise en place d'un **VPN sécurisé avec OpenVPN** et gestion centralisée des logs réseau via **Loganalyzer** sur Linux, réalisé en classe.

## Technologies utilisées
| Technologie | Rôle |
|---|---|
| OpenVPN | Tunnel VPN sécurisé |
| Loganalyzer | Interface web de gestion des logs |
| Linux | Système d'exploitation |
| Syslog / rsyslog | Collecte des journaux système |

## Fonctionnalités
- Configuration du serveur OpenVPN
- Génération et distribution des certificats clients (PKI)
- Collecte et visualisation des logs réseau via Loganalyzer
- Détection d'anomalies par analyse de logs
